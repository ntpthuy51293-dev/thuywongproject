# Hot Economic + Technology Topics: Bottleneck Research

Goal: spot hot topics in the economy and technology, find the bottlenecks people are discussing, research the public companies working to solve them, and use that to find early-trend stock ideas for a quarterly or annual horizon.

Everything here is research, not financial advice.

## Layout

- `watchlist.csv` current scored watchlist, refreshed each review
- `reports/` dated scans, one file per research pass (`YYYY-MM-DD-<topic>.md`)
